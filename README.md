# ITP4233 Q4 - Hands-On Evaluation of Free Generative AI Models & APIs

This repository contains the source code for testing three free Generative AI APIs as part of the ITP4233 Generative AI Applications assignment.

## Selected APIs

1. **OpenRouter** (`openai/gpt-3.5-turbo`)
2. **Cloudflare Workers AI** (`@cf/meta/llama-3.1-8b-instruct`)
3. **Cohere** (`command-r-08-2024`)

## Files

- `1_openrouter.py` – Test script for OpenRouter
- `2_cloudflare.py` – Test script for Cloudflare Workers AI
- `3_cohere.py` – Test script for Cohere
